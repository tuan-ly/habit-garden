```

## 2. Emotional Design System

### 2.1 Plant-Mood Connection

**How Plants Reflect User Emotion**:

```
USER MOOD INPUT:
┌─────────────────────────────────────────────────────────────┐
│ Daily mood check: "How are you feeling?"                    │
│                                                              │
│ [Great]  [Good]  [Okay]  [Low]  [Struggling]                │
│   🌟      😊      😐      😔       😢                        │
└─────────────────────────────────────────────────────────────┘

PLANT VISUAL RESPONSE:

Great Mood:
┌─────────────────────────────────────────────────────────────┐
│ - Plants appear more vibrant                                │
│ - Subtle sparkle/glow effect                                │
│ - Flowers more open                                         │
│ - Garden lighting brighter                                  │
│ - Background music more upbeat                              │
└─────────────────────────────────────────────────────────────┘

Good Mood:
┌─────────────────────────────────────────────────────────────┐
│ - Plants appear healthy, normal                             │
│ - Gentle sway animation                                     │
│ - Standard garden ambiance                                  │
└─────────────────────────────────────────────────────────────┘

Okay Mood:
┌─────────────────────────────────────────────────────────────┐
│ - Plants appear normal                                      │
│ - Slightly muted colors                                     │
│ - Garden feels "quiet"                                      │
└─────────────────────────────────────────────────────────────┘

Low Mood:
┌─────────────────────────────────────────────────────────────┐
│ - Plants "lean toward user" (empathy gesture)               │
│ - Soft, comforting color palette                            │
│ - Rain/mist effect (cleansing visual)                       │
│ - Comfort prompts appear                                    │
│ - XP requirements reduced for the day                       │
└─────────────────────────────────────────────────────────────┘

Struggling Mood:
┌─────────────────────────────────────────────────────────────┐
│ - Plants "gather around" (protective circle)                │
│ - Warm, amber lighting                                      │
│ - Gentle wind sounds                                        │
│ - "Take care mode" - minimal requirements                   │
│ - Option: "Just sit in garden" (no tasks)                   │
│ - Resources offered (if enabled)                            │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 Comfort Mechanics (When User Fails)

**Failure Response System**:

```
IMMEDIATE RESPONSE (Plant Dies):
┌─────────────────────────────────────────────────────────────┐
│ WRONG approach:                                             │
│ "Your plant died. -50 XP. Try harder next time."            │
│                                                              │
│ RIGHT approach:                                             │
│ "Your [Rose] has passed. She remembers your 15 beautiful    │
│  days together."                                            │
│                                                              │
│ [Show plant's "memory" - timeline of good moments]          │
│                                                              │
│ "Every gardener loses plants. It's part of growing.         │
│  Would you like to..."                                      │
│                                                              │
│ [Plant a memorial seed]  [Try again with same habit]        │
│ [Rest for now]           [Talk about what happened]         │
└─────────────────────────────────────────────────────────────┘

STREAK BREAK RESPONSE:
┌─────────────────────────────────────────────────────────────┐
│ WRONG approach:                                             │
│ "You broke your 45-day streak! Back to 0!"                  │
│                                                              │
│ RIGHT approach:                                             │
│ "Your 45-day journey didn't end - it evolved.               │
│  You completed 45 days. That's still real."                 │
│                                                              │
│ [Show: "Total days completed: 45 (Personal best!)"]         │
