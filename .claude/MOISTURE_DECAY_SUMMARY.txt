  ├─ If last_watered_at TODAY (user's timezone), decay skipped

✓ Timezone Awareness
  ├─ Uses user's timezone from profiles.timezone
  ├─ Defaults to: Asia/Ho_Chi_Minh if not set
  └─ Check via: SELECT timezone FROM profiles

✓ Moisture Already Zero
  ├─ If current_moisture = 0, already dead
  ├─ No further decay possible
  └─ Check via: SELECT current_moisture FROM plants

┌──────────────────────────────────────────────────────────────────────────────┐
│ FUNCTION DEFINITION                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

Function: public.update_daily_moisture()
Location: supabase/migrations/20260303_fix_moisture_decay_all_statuses.sql
Language: PL/pgSQL
Returns: void

Logic Flow:
  1. SELECT all plants with status IN (growing, thriving, resting, waiting, sleeping)
  2. FOR EACH plant:
     a. Get user's timezone
     b. Convert NOW() to user's local date
     c. IF watered today, SKIP
     d. ELSE calculate: new_moisture = current_moisture - decay_rate
     e. IF new_moisture ≤ 0: mark as dead
        ELSE: update current_moisture
  3. LOOP END

Check Plant Decay Status:
────────────────────────
SELECT
  p.id,
  p.name,
  p.status,
  p.current_moisture,
  p.last_watered_at,
  pt.moisture_decay_rate,
  COALESCE(pr.timezone, 'Asia/Ho_Chi_Minh') as effective_tz
FROM plants p
JOIN plant_types pt ON p.plant_type_id = pt.id
LEFT JOIN profiles pr ON p.user_id = pr.id
WHERE p.status NOT IN ('dead', 'mature')
ORDER BY p.updated_at DESC;
